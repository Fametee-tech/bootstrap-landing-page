# Nova Digital — Bootstrap Landing Page

A responsive landing page made for the Frontend Development class assignment.

## Assignment requirements covered

- Uses Bootstrap 5.3 through the official CDN (no local Bootstrap installation needed).
- Responsive layout using Bootstrap's `container`, `row`, and `col-*` grid classes.
- Hero section with a heading, supporting text, and call-to-action buttons.
- Services/features section with three Bootstrap cards.
- Buttons and navigation links.
- About section, contact call-to-action, and footer.
- Responsive mobile navigation powered by the Bootstrap JavaScript bundle.
- Custom styling in `css/style.css`.

## How to run

1. Download and extract the ZIP file.
2. Open `index.html` in a browser while connected to the internet (the Bootstrap, icon, and Google Fonts CDNs need internet access).

## Git and GitHub submission

Open a terminal inside the extracted `bootstrap-landing-page` folder and run:

```bash
git init
git add .
git commit -m "Build responsive Bootstrap landing page"
git branch -M main
```

Create a new **empty** repository on GitHub, then replace `YOUR-USERNAME` and `YOUR-REPOSITORY` below with your actual details:

```bash
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Then share the repository URL with your instructor, for example:
`https://github.com/YOUR-USERNAME/YOUR-REPOSITORY`

If Git asks you to sign in, complete GitHub authentication in your browser. Do not put your password or access token inside the repository or this README.

## Customization

The sample brand is **Nova Digital**. You can keep it as the demo identity or replace the name and sample copy with your own business/brand details. The email link uses a placeholder address (`hello@novadigital.example`) for demonstration; replace it with a real contact address if needed.
